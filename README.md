Телеграмм бот - помощник бригадира потока.

Что умеет бот:

1. Навигация по кнопкам
2. Навигацию по тексту сообщения пользователя
3. Хранит информацию по операциям\статусам
4. Дает инструкции по выполнению базовых задач
5. Хранит информацию по нормативам и KPI сотрудника, с возможностью обновлять данные прямо из чата
6. Ограниченный доступ к пользованию ботом, проверяет доступ по участникам чата
7. Заполняет часовой отчет по потоку с помощью парсинга EXCEL-файлов и форматировано отправляет результат в чат с отчетами
